# レッドストーン版の下調べ（26.2 実機測定）

演奏をコマンドではなくレッドストーン回路でやる版のための測定。
**すべて headless サーバの実機で測った値**で、wiki からの引き写しではない。

測り方は `/tick rate 1` でゲームを 1 tick/秒 に落として実時間で観測する。
`/tick freeze` + `/tick step` は**非同期**で、コマンドを投げた直後に問い合わせると
まだ進んでいないことがあるため使えない。

---

## 遅延

| 素子 | 1 段あたり |
|---|---|
| リピーター delay=1 | **2 game tick** |
| リピーター delay=2 | 4 game tick |
| コンパレーター | 2 game tick |
| レッドストーンダスト | 0（即時、15 ブロックまで） |

**逐次遅延の最小は 2 game tick = 10Hz。** バニラのレッドストーンだけでは
1 tick 刻みは出せない。オブザーバーは信号を中継しない（列が止まる）ので
抜け道にならない。

### 20Hz を出す方法

**2 レーンを 1 tick ずらして走らせる。** レーンごとの遅延は 2 tick のままだが、
互い違いに配置すれば全体として 1 tick 刻みになる。

ずらすための 1 tick 遅延素子はレッドストーンには無いので、
**開始だけコマンドでやる** — tick T にレーン A、tick T+1 にレーン B を起動する。
以降は純レッドストーンで走るので、演奏中にコマンドは動かない。

## リピーターの向き

`facing` は**入力側**を指す。西から東へ流したいなら `facing=west`。

    [redstone_block x=1] [repeater facing=west x=2] [lamp x=3]  → 点く
    [redstone_block x=1] [repeater facing=east x=2] [lamp x=3]  → 点かない

直感と逆なので、ここを推測で書くと回路が丸ごと逆向きになる。

## 音符ブロックの鳴らし方

| 置き方 | 鳴るか |
|---|---|
| ダストの横に隣接 | **鳴らない** |
| ダストの真上 | 鳴らない |
| ダストの斜め上 | 鳴らない |
| ダストの真下（真上がダスト） | 鳴らない |
| **リピーターが向いた石の隣** | **鳴る** |
| **強く電力を受けた石の真上** | **鳴る** |

「ダストの隣に置けば鳴る」は**間違い**。ダストが弱く電力を与えるのは
真下のブロックだけで、横のブロックには自分が向いているときしか与えない。

使えるのは **リピーターで強く電力を受けた石**を中継にする形だけ:

    [repeater] → [石] → その隣・その真上の音符ブロックが鳴る

石 1 個につき、隣接する面の音符ブロックが鳴る。真上も含めて最大 5 個。

## まだ決めていないこと

- 1 平面に 20 音を並べる形。石 1 個では 5 個までなので、石を並べる必要がある
- コリドーの長さ。パルスは 2 ブロック / 2 tick = 1 ブロック / tick で進むので、
  224 秒の曲で 4480 ブロック。コマンド版（速度 0.365）の約 2.7 倍
- プレイヤーの移動速度をパルスに合わせる必要がある（20 ブロック/秒）
